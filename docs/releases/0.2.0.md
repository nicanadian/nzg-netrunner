# 0.2.0 — Alpha release

Status: **published alpha release**. All required automated release checks passed. The previous release is 0.1.0; its historical `alpha-build-1` tag and ZIP filenames remain compatible.

## Upgrading from 0.1.0

Use **Quit game** in the old launcher before opening 0.2.0. An already-running old server is reused by subsequent launches, so quitting it first ensures the new code starts. Export a replay as a portable backup. Using the same browser and default loopback address preserves its save storage.

## Included changes

- Separate character and deck selection for both human and AI sides. Ten ready-made Gateway lists include two Tāo alternatives and a Jinteki economy alternative, with readable style/cost summaries.
- Deck library: clone, edit, import, export and save custom lists locally. Games embed exact custom/variant documents so later library changes cannot rewrite an existing replay.
- A visible card-pool switch opens 21 attributed official Gateway + Elevation sample lists. This profile stays labelled experimental; card definitions and initial tests are not complete rules or AI certification.
- Sharper Elevation artwork: all 82 fronts and both reverse identity faces come from native 746×1033 official PDF images, with genuine 300/600/743-pixel browser variants and pixel-level verification.
- Clearer install, payment, encounter and access flows; optional boosts and abilities are moved away from the primary action list where appropriate. Better Keep/Mulligan, Nico timing, ice approach, damage, counter and replay diagnostics.
- Explicit unrezzed-ice warnings. Skipping opponent animation preserves required rez-shortage reviews, including reviews already queued behind other actions.
- More usable setup at desktop and phone sizes; start controls stay reachable and custom decks are not labelled as baseline lists.
- UI-free offline engine CLI: validate decks, seeded matches, worker-pool matchup matrices, resume, full decision traces and frozen-runtime replay. The portable engine package is a separate development tool.
- Search optimizations preserved all decisions in retained comparison runs. Benchmark policies are existing heuristics, not trained models; hidden-information fairness and full Elevation strategy remain unaudited.

## Compatibility and limitations

Gateway remains the default. Existing deck IDs and replay rules revisions remain available. Gateway and Core save slots are separate. Packaged games use the same loopback origin as 0.1.0; use the same browser/port to retain saves, or export/import a replay when transferring from the development server.

These are unsigned alpha packages (Mac apps receive ad hoc signatures, not notarization). Native smoke checks cover startup/assets/help/relaunch/quit, not every card interaction or complete manual matches on every operating system. The optional chat helper requires separate configuration; gameplay and the reference guide work offline.
