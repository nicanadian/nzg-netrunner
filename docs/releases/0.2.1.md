# 0.2.1 — Deckbuilding and visibility fixes

Status: **build candidate in qualification**. Public 0.2.0 downloads remain unchanged.

## Changes since 0.2.0

- One deck picker per side groups lists by character, with direct Tune this deck and Save & use actions. Valid deck selections persist across reloads.
- Fifteen distinct Gateway ready-made lists, with at least two choices for each Gateway character. Existing deck IDs and saved game snapshots remain unchanged.
- Identity-aware influence labels and filters show actual per-copy costs and the total used by each included card. Character faction is shown beneath the dropdown.
- Character switching previews a matching legal ready-made deck or an explicit keep-cards choice. It no longer silently turns another faction's list into an over-budget deck. Existing invalid drafts have a recovery path; opposite-side changes never keep wrong-side cards.
- Card thumbnails, full-resolution artwork and readable card text in the builder. Included replacement cards show their quantity with a restrained cyan marker.
- Compact card rows and horizontal quantity controls; consistent palette and component styling across library, editor, import and card preview. Mobile uses a single active list; keyboard focus and sticky controls were checked.
- Copy-limit buttons prevent accidental extra copies. Invalid drafts remain editable, and switching to another ready-made list does not overwrite a saved custom deck.
- Both players' status bars show current cards in hand and maximum hand size.

## Compatibility

Use Quit game in the older launcher before starting this build, so an already-running older server is not reused. The default packaged browser address remains unchanged. Games and custom decks remain local to the browser/origin; export a replay or library backup for portable copies.

Gateway remains the default. Gateway + Elevation remains experimental, with its card-rules/AI audit incomplete. These changes do not certify full Elevation support or competitive deck balance.
