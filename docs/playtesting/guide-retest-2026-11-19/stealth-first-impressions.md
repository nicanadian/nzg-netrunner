# Fresh first impressions — Stealth, 19 November 2026

Saved before reading any prior playtest reports. DOM-only review: preview snapshot timed out; no visual assessment.

The Vantage Stealth learning path clearly gives an actual 27/54 versus 27/54 sample and warns against treating it as strength. The dependency example is immediately useful: event → Touchstone → Corsair, two stealth payments against Palisade, then an ordinary credit for the break. That is enough arithmetic to avoid assuming ordinary credits can fund reductions. It still assumes I know what counts as an event and how to install/use these cards; I will test actual prompts.

The expanded worked edit is unusually concrete: cut one Pantograph, add one DZMZ, retain all Touchstones, same 40 cards and 8/15 influence. It states opportunity cost and a useful observation target. I expect to verify this in the builder, not infer it from legality.

The broad before-play reminder to prepare income, read damage subroutines, and reassess advancing remotes is sensible but generic; there is no turn-by-turn opening sequence. This appears a guide for someone who has played Gateway, consistent with the section title, rather than a complete new-player tutorial.

Changing card sets from Gateway to Vantage selected Loup even though Tao is the first option in the DOM list. I will choose the explicit Stealth path's Open starting deck action, so this selection ambiguity should not affect the experiment.
