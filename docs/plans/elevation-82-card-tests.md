# Elevation: 82-card rules test plan

Release checklist, not a claim of full certification. The companion JSON and `eval/offline-engine/elevation-coverage.json` now link partial ability evidence for all 82 cards; every protocol below remains a release requirement. Every row requires protocol A–H in `elevation-full-support.md`, explicit expected state transitions, current rule/ruling references, and links to executable evidence. Existing fixtures and Chrome evidence must be audited and reused rather than discarded. A simulation merely drawing a card is not coverage of its ability.

Wave 1 = close gaps in the first 17; wave 2 = six missing NBN definitions; wave 3 = remaining Runner cards; wave 4 = remaining Corp cards. Shared mechanics may move earlier when dependencies require. Wave 5 is cross-card and deck integration.
