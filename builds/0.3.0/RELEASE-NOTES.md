# 0.3.0 · alpha release candidate

Vantage Point joins the local game as a separate preview, with all 66 cards, four new identities, local artwork and selectable/tunable decks. Gateway remains the default; Elevation and Vantage keep their experimental labels. This release does not claim tournament rules or strategic AI certification.

The new lobby pairing and learning guide links exact deck matchups to setup and tuning. It includes validated cut/add examples, role-specific opening checklists, a Phoenix/Doomscroll encounter example, stealth-funding guidance and advice for adapting when the board changes. Matchup records describe the bundled lists in AI tests; custom edits remain unbenchmarked.

Custom decks retain a baseline across saves so cumulative changes stay visible. Experiment notes save locally by deck, side and card set. Copy baseline plan fills empty intention fields without overwriting existing text or carrying old game results into the new revision.

Other changes improve encounter and payment clarity, support/dependency advice, two-click labels, targeted card interactions, AI legal-choice handling, and restoring saved games. Previous versioned profiles remain available; an incompatible historical decision is rejected visibly rather than applied to another state.

## Upgrade

Quit the older local launcher before starting this one. Use the same browser and default address to retain local saves and decks. Export replays and a deck-library backup for portable copies. Development-server storage at port 5173 is separate.
